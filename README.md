# Build-your-first-agent-in-Copilot-Studio-hands-on-lab
Building a IT Concierge agent end to end in Copilot Studio with the GitHub Copilot harness: knowledge, live SharePoint data, skills and a workflow

## Resources

- Original repository: https://github.com/MariuszFerdyn/ignite26-PREL36
- Video: https://youtu.be/o4EFtZ2kX6M

## In this video and lab you learn

- **Knowledge** – ground the agent in Microsoft support sites, a SharePoint site, and an uploaded document.
- **Tools** – add the SharePoint Get items connector.
- **Skills** – create skills to guide the answers.
- **Workflow** – send a device request email using SharePoint item data, called by the agent only after the user confirms.
- **Testing** – test the agent.
- **Publish** – release the agent to Microsoft Teams and Microsoft 365 Copilot.
